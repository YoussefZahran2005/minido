# <img src="https://img.shields.io/badge/Minido-1E3A5F?style=for-the-badge&logoColor=white" alt="Minido">

> **A minimal task management application built with Java and Spring Boot.**

---

## ✦ Features

|   | Feature                                                            |
| - | ------------------------------------------------------------------ |
| ✓ | **Create** tasks with a title, description, due date, and priority |
| ↻ | **Update** existing tasks and their status                         |
| × | **Delete** tasks                                                   |
| ◉ | **Complete / Reopen** tasks                                        |

---

## ⚙ Tech Stack

**Backend**

`Java` · `Spring Boot` · `Spring Data JPA`

**Database**

`PostgreSQL`

---

## 🚀 Getting Started

### Prerequisites

* Java 25 (For best experience)
* Maven
* PostgreSQL

### Installation

```bash
git clone https://github.com/YoussefZahran2005/minido.git
cd minido
```

Configure your PostgreSQL database connection, then run:

```bash
./mvnw spring-boot:run
```

**Windows:**

```bash
mvnw.cmd spring-boot:run
```
